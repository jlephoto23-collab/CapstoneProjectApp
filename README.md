# CapstoneProjectApp — EduFlow LMS

**Moqebelo Jonas Lephoto** · Module 1 Web Development Capstone

## What this is

EduFlow is a student Learning Management System (web app) with:

- Login / Register
- Course registration with entry requirements
- Document uploads (ID, Matric, supporting docs)
- Auto approve/reject based on requirements
- Admin application review
- Courses, modules, unit standards
- Practical assessments, grading, pass/fail
- Student portfolio site

## Open in browser (no install)

1. Download or clone this repo
2. Open `web/lms.html` in Chrome / Edge / Firefox
3. Demo admin: `admin@eduflow.co` / `admin123`

Also open `web/portfolio.html` for the portfolio.
